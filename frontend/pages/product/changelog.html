Product update

Loops for product management

Loops are recurring agent workflows for teams. They now respond to more workspace activity, including changes to initiatives, projects, and cycles. They can also edit documents and post updates to connected communication channels.

Teams change project plans all the time. It is not the change itself that is hard, but the follow-through: updating documents, creating issues, and keeping everyone informed.

Loops can now handle that coordination for you. For example, when a project's target date changes, a loop can automatically update the launch plan and post an update explaining what changed, why it changed, and who needs to act.

Trigger from across your workspace

New triggers allow automated workflows to respond to changes throughout your workspace.

  • Project and initiative changes to status, ownership, target dates, milestones, membership, and labels.
  • New project and initiative updates and comments.
  • Cycles being created, started, or completed.
  • Issue changes to status, priority, assignee, cycle, project, or labels.

Edit documents

In addition to creating issues and updating projects and initiatives, Loops can now edit documents. When scope or timing changes, automated workflows can update the relevant document so plans stay aligned.

Share updates

Loops can draft and post tailored updates using context from your workspace and connected tools, helping teams stay informed about what changed and what happens next.

Continue any run

Each loop run starts a conversation with the AI agent. Once it finishes, you can continue that conversation to review the work, add context, or direct what happens next.

Loops credits available through the end of the year

Introductory Loops credits have been extended, giving teams more time to test recurring workflows and explore how automated coordination can fit into their processes.

Callout components

Use callout components to draw attention to important information in issue and project descriptions, as well as documents. Choose a color, icon, or emoji to match the context.

In PR descriptions, callouts can carry their emphasis across to the connected development workflow.

Type /callout to get started.

Engineering

Coding sessions: environments, browser use, and updated pricing

Nexora Agent can now set up, run, and test your code before returning its work. This reduces handoffs and allows coding sessions to return work that has already been validated.

We are also introducing clearer pricing so teams can better understand and control AI credit usage.

Configurable environments

Coding sessions automatically adapt to each codebase's configuration, with support for common development environments and languages.

During a session, the agent can detect and install required toolchains and dependencies.

  • Runtime version configuration
  • Setup scripts
  • Environment variables
  • Project-specific dependencies

Browser testing

Once an application is running, the coding agent can test the work directly in the browser.

It can navigate through a flow, verify implementation, and capture before-and-after screenshots so visual changes can be reviewed alongside the code.

If a problem is discovered, the agent can make a fix, rerun the test, and return the work with validation completed.

Transparent pricing

Coding sessions now use a pricing model based on model usage and sandbox runtime.

Model usage

Tokens are charged according to the provider's published rates.

Sandbox runtime

Runtime usage is calculated separately from model usage.

Together, model usage and runtime determine the AI credit cost of a session. The usage dashboard provides a breakdown of token usage and cost by model.

Administrators can also configure workspace-wide and per-user spending limits that reset daily, weekly, or monthly.

Team initiatives

Initiatives define company-level goals and organize the projects that contribute to them. Teams can now be assigned to lead initiatives, making ownership and responsibility clearer.

Strategy may begin at the company level, but teams carry that strategy forward. Team-led initiatives provide a clearer connection between high-level objectives and the work being delivered.

For work that requires tighter access, initiatives led by private teams can be restricted to team members.

Clear initiative ownership

Assigning a lead team gives every initiative a clear group responsible for driving the work and connecting it back to broader company objectives.

Private initiatives

Initiatives led by private teams can remain visible only to the appropriate team members, creating a more controlled environment for confidential planning, audits, regulated work, and restricted projects.

Enterprise-managed authorization for MCP

Enterprise workspaces can manage employee access through supported identity-management systems.

Administrators can manage access centrally while applying existing workspace permissions.

Mobile

Coding sessions on mobile

Your coding session does not have to stop when you leave your desk. Use the Nexora mobile experience to review code changes, comment on specific lines, and iterate with the coding agent.

Open any diff and switch to the Changes tab to inspect the code. When you spot something that needs changing, tap the relevant line to add it to your message and guide the coding session.

A new Assigned section also provides visibility into delegated coding sessions and their current status.

Guided Reviews are now generally available

Guided Reviews break diffs into focused sections with explainers that help reviewers understand what changed and why.

Larger pull requests can now receive guided review sections with expanded context and improved latency.

Support for GitHub teams in reviews

Reviews can now be assigned to GitHub teams. Review requests assigned to a team appear in a dedicated section of the review inbox.

Signed commits for coding sessions

Coding sessions now support signed commits. Developers can configure an SSH or GPG key to enable commit signing.

Workspace administrators can also require signing keys before coding sessions can be used.

GitHub Copilot for Nexora

Teams using GitHub Copilot can assign issues directly to Copilot's cloud agent and continue coordinating development work from the workspace.

Model and agent settings can be configured while comments and issue context remain available throughout the development process.
